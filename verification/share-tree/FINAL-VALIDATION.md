## 发现的问题及处理

- 修复下载时序：在树加载完成前或换季图片未解码时，旧版允许下载占位卡或上一季图片。现将下载绑定 URL、季节与当前截图。两条测试先红后绿，并实际检查保存文件。
- 修复手机二维码留白、截图失败时切换按钮状态、语言切换时 canvas 生命周期以及小字对比度；已在本地与线上覆盖。
- 移除 Three.js 已废弃阴影模式的使用。
- 首次 Vite preview 49/50：服务器 SPA fallback 导致未知日期返回 200；换用现有生产静态服务器后保留 404 断言通过，最终本地 59/59。[初次证据](first-vite-preview-results.json)
- 首轮 GitHub Linux CI 57/59：慢速运行器在点击返回前已完成动画，测试错过瞬态。现使用受控时钟停在 160ms 执行中途关闭/故障注入，保留严格断言，无跳过、无放宽、无重试。[初轮失败](initial-ci-animation-failure.log)
