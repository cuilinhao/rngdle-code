## 后台

通过用户已登录的「林豪」Chrome 配置阅读指定教程并在 Adsterra 提交 `rngdle.art`。网站 ID `6078332`，三个广告单元均已在后台确认 **Active**：`31419719`（320×50）、`31419718`（300×250）、`31419717`（Native Banner）。成人广告关闭；未创建 Popunder。

代码中的三个 Key、完整脚本域名和尺寸均取自各单元的 Get Code 界面。公开投放脚本可取得有效 JavaScript；静态检查确认 Banner 同步捕获 `atOptions` 并将广告 iframe 插入其脚本所在容器，Native 有一次初始化限制并监听 SPA 导航。因此 Banner 串行加载，Native 脚本每个 document/Key 加载一次，语言切换保留首页容器。
